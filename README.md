🟢 Gemini UI Optimizer: User Guide
This is a UI optimization extension specifically developed for the Gemini web interface, designed to provide the following features:

Eye-Care Mode: Automatically adjusts the background color to reduce eye strain during long-term use.

Auto-Generated Index: Creates a navigation sidebar based on your conversation history (supports recognition of user-uploaded images).

Minimalist Design: The chat box automatically becomes invisible when idle, providing a wider reading area.

Step 1: Get the Extension Code
Visit the project repository: https://github.com/Marcia-van/Gemini_UI_Optimizer

Click the green "Code" button and select "Download ZIP".

Once downloaded, extract the ZIP file into a permanent folder on your computer.

Step 2: Install in Google Chrome
Open Chrome and type chrome://extensions/ in the address bar, then press Enter.

Locate and toggle the "Developer mode" switch in the top right corner.

Click the "Load unpacked" button that appears in the top left.

In the pop-up window, select the folder you just extracted (the one containing the manifest.json file).

Step 3: Getting Started
Open the Gemini official website.

You will notice the background has switched to an eye-friendly color.

Hover your mouse over the green "INDEX" bubble on the right to expand the auto-generated navigation menu.

Click the "Chat" bubble at the bottom right to quickly restore the input box.

🟢 Gemini UI Optimizer 使用教学
这是一个专门为 Gemini 网页版开发的 UI 优化插件，可以实现：

护眼模式：自动切换背景色，缓解长时间看屏幕的疲劳。

自动生成目录：根据聊天内容自动生成侧边栏跳转目录（支持识别用户上传的图片）。

极致简洁：对话框在闲置时会自动隐形，让阅读区域更宽阔。

第一步：获取插件代码
访问项目地址：https://github.com/Marcia-van/Gemini_UI_Optimizer

点击绿色的 "Code" 按钮，选择 "Download ZIP"。

下载后，将压缩包解压到你电脑的一个固定文件夹中。

第二步：在谷歌浏览器（Chrome）中安装
打开 Chrome 浏览器，在地址栏输入 chrome://extensions/ 并回车。

在页面右上角，找到并开启 “开发者模式” (Developer mode) 开关。

点击左上角出现的 “加载已解压的扩展程序” (Load unpacked)。

在弹出的窗口中，选择你刚才解压出来的文件夹（即包含 manifest.json 的那个文件夹）。

第三步：开始使用
打开 Gemini 官网。

你会发现背景变成了护眼色。

将鼠标悬停在右侧绿色的 "INDEX" 小球上，即可展开自动生成的目录。

点击右下角的 "Chat" 小球可快速唤回输入框。
